# Huh? Cat Clicker - The Insanity Game

画面をクリックすると、猫が「Huh?」と鳴くだけ。

## 🎮 デモページ (Demo)

https://m-masaki72.github.io/HuhCatClicker/

## ✨ 主な特徴 (Features)

- 無限のHuh?: 画面のどこをクリックしても、Huh?猫があなたの呼び声に応えます。
- 予測不能な猫: 猫は毎回、ランダムな位置・大きさ・角度で出現します。二度と同じHuh?はありません。
- ピッチランダム: 同じ声の猫はいません。毎回ランダムな高さの「Huh?」があなたの鼓膜を刺激します。
- スコア記録: あなたがどれだけHuh?したか、ブラウザが記憶しています。ページをリロードしても狂気は続きます。
- 狂気の共有: Twitter(X)シェアボタンで、あなたのHuh?カウントを世界に自慢できます。

## 🌟 レアキャラクター 🌟

クリックを続けていると、ごく稀に特別な猫が登場します…！

- ゴールデンHuh?キャット: 5%の確率で出現する金色の猫。登場すると5回ループ再生し、そのたびに巨大化していきます。
- レインボーHuh?キャット: 5%の確率で出現する虹色の猫。流れ星のように画面を駆け抜けながら、「Huh?」をループ再生します。

## 遊び方 (How to Play)

1. 開く。

1. クリックする。

1/ Huh?
